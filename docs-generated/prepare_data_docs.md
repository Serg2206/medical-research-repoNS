# Документация для кода подготовки данных

## Описание функционала

Этот скрипт Python предназначен для подготовки данных, которые затем будут использоваться для обучения и тестирования моделей машинного обучения. Он принимает на вход CSV-файл, содержащий данные, и разделяет эти данные на обучающую и тестовую выборки. Разделенные данные затем сохраняются в указанной директории.

## Функции

### `prepare_data(input_csv, output_dir, test_size=0.2)`

Эта функция принимает на вход CSV-файл, директорию для сохранения обработанных данных и размер тестовой выборки (по умолчанию 0.2, или 20% от общего объема данных).

#### Параметры

- `input_csv` (str): Путь к входному CSV-файлу. CSV-файл должен содержать столбцы 'text' и 'label'.
- `output_dir` (str): Директория для сохранения обработанных данных. Если директория не существует, она будет создана.
- `test_size` (float, optional): Размер тестовой выборки (доля от общего объема данных). По умолчанию равно 0.2.

#### Возвращаемое значение

Функция не возвращает значение. Она сохраняет обработанные данные в указанной директории.

## Примеры использования

```python
prepare_data('data.csv', 'output_dir', test_size=0.3)
```
В этом примере данные из файла 'data.csv' будут разделены на обучающую и тестовую выборки, причем тестовая выборка будет составлять 30% от общего объема данных. Обработанные данные будут сохранены в директории 'output_dir'.

## Запуск скрипта из командной строки

Этот скрипт также можно запустить из командной строки. Для этого используйте следующую команду:

```bash
python script.py --input_csv data.csv --output_dir output_dir --test_size 0.3
```
В этом примере параметры передаются через аргументы командной строки.
