# Документация

## Описание функционала

Данный код представляет собой пример реализации нейронной сети для медицинских целей с использованием библиотеки PyTorch. Он включает в себя определение архитектуры модели и функцию для обучения модели.

## Класс MedicalNet

### Описание

Класс `MedicalNet` представляет собой модель нейронной сети, которая состоит из трех полносвязных слоев (`fc1`, `fc2`, `fc3`) и слоя dropout.

### Параметры

- `input_size` (int): Размер входного слоя.
- `hidden_size` (int): Размер скрытого слоя.
- `output_size` (int): Размер выходного слоя.

### Методы

- `forward(x)`: Производит прямой проход через нейронную сеть.

## Функция train_model

### Описание

Функция `train_model` обучает модель `MedicalNet` на предоставленных данных.

### Параметры

- `data` (numpy.ndarray): Данные для обучения.
- `labels` (numpy.ndarray): Метки классов для данных.
- `input_size` (int): Размер входного слоя.
- `hidden_size` (int): Размер скрытого слоя.
- `output_size` (int): Размер выходного слоя.
- `epochs` (int, optional): Количество эпох для обучения. По умолчанию равно 20.
- `batch_size` (int, optional): Размер пакета данных для одной итерации обучения. По умолчанию равно 32.

### Возвращаемые значения

Функция не возвращает значений, но обучает модель `MedicalNet`.

## Пример использования

```python
# Импорт необходимых библиотек
import numpy as np

# Генерация данных
data = np.random.rand(1000, 10)
labels = np.random.randint(0, 2, 1000)

# Обучение модели
train_model(data, labels, input_size=10, hidden_size=32, output_size=2, epochs=50, batch_size=64)
```

В этом примере мы генерируем случайные данные и метки, а затем обучаем на них модель `MedicalNet`.
