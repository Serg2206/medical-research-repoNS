# Документация к коду

## Описание функционала

Данный скрипт предназначен для использования предобученной модели классификации последовательностей (Sequence Classification) из библиотеки transformers. Он принимает на вход путь к модели и текст, который необходимо классифицировать, и возвращает вероятности принадлежности текста к каждому из классов.

## Функции и методы

### infer_model(model_dir, text)

Функция для инференса модели.

#### Параметры:

- `model_dir` (str): Путь к директории, содержащей предобученную модель.
- `text` (str): Текст, который необходимо классифицировать.

#### Возвращаемое значение:

- `probabilities` (list): Список вероятностей принадлежности текста к каждому из классов.

## Пример использования

Для использования скрипта необходимо запустить его из командной строки, указав путь к модели и текст для анализа:

```bash
python script.py --model /path/to/model --text "Текст для анализа"
```

В ответ скрипт выведет вероятности принадлежности текста к каждому из классов:

```bash
Результаты предсказания: [[0.001, 0.999]]
```

В данном примере вероятность принадлежности текста к первому классу составляет 0.001, а к второму классу - 0.999.
